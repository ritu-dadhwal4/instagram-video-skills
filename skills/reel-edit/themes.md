# Reel themes (offer these when there is no design file)

**In plain words:** a theme is a ready-made colour and font set. Pick one and every card, caption, highlight and end card in the reel uses it, so the whole video looks like one family.

Offer 3 or 4 that suit the footage, recommended first, each as one line: name, the feel, the colours. Once one is picked, write it out as `design.md` (same fields as design.example.md). All fonts are free Google Fonts.

## Rules
- One accent colour only. Two highlight colours look like a mistake.
- Text on the accent colour must stay readable (check contrast 4.5:1); on yellow or lime use the dark text colour.
- Captions over a busy picture get the outline-and-shadow or the solid box from the theme, never thin text.
- A theme picked from someone's reference pictures is a lookalike in colour and mood, never a copy of another creator's logo, mascot or exact layout.
