# omni-restyle

**In plain words:** same clip, new paint. Turns ordinary footage into a drawn or stylised version so everything in the video looks like it belongs together.

## Steps
1. Choose ONE target style for the whole video and save a reference frame in `assets/style-ref.png`.
2. Restyle each clip against that same reference, never from a fresh text prompt.
3. Compare first, middle and last frames with the original: the subject, pose and timing must be unchanged.

## Rules
- One style per video.
- Do not restyle screen recordings; text becomes unreadable.
- Ask before spending credits. Keep the original clip beside the restyled one.
