# longform-edit (edit format)

**In plain words:** the long YouTube video. Slower, in chapters, switching between the face, the screen and graphics.

**Use when:** the video is horizontal and longer than about 3 minutes.

## Layout
- Chapters from the script, each opening with a 1.5 s title card; export the chapter times for the YouTube description.
- Change what is on screen at least every 8 s.
- Rough mix to aim for: face 20%, screen 40%, cards 25%, full-page 15%.
- Captions optional; if on, lower third, one line.

## Rules
- Run the pipeline per chapter, then join; review frames from EVERY chapter.
- The first 30 s show the end result before explaining how.
- Motion, colours and fonts come from mg-kit. Face placement comes from take-geometry.
- These measurements are a starting point written by us, not copied from a reference. Run learn-style on a reel the creator likes to replace them with measured numbers.
