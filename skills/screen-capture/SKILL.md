# screen-capture (stage 4)

**In plain words:** show the thing being talked about. When the creator says "open this site and click here", the viewer should see that exact site, recorded cleanly.

## Steps
1. Take the `screen` rows from `work/asset-plan.md`.
2. Capture each from the live page with the browser tools at 2x size. Hide cookie banners, personal emails and logged-in account names first.
3. If the creator supplied their own screen recording, sync it to the camera audio: find the same spoken word or click sound in both and line them up.
4. Save to `assets/screens/<cut-id>-<name>.png|mp4` and mark the row "have".

## Rules
- Only real pages. Never mock up a screen of someone else's product.
- The part being discussed must be readable on a phone: zoom so that text is at least 28 px tall in a 1080-wide frame.
- Never show their email, payment details, API keys or admin pages.
- A capture older than the claim it supports is retaken (prices and UI change).
