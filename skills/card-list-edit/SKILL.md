# card-list-edit (edit format)

**In plain words:** a countdown. Each item gets its own card with a number, a name and one line.

**Use when:** the script is a list: 5 tools, 7 tips, 3 mistakes.

## Layout
- Hook on full face, then for each item: number badge + title card (1 s) → proof (screen or b-roll) with the card shrunk to the top.
- A progress marker (3/7) stays in one corner.
- Same card template for every item.

## Rules
- Items are equal length within about 20%.
- Names, logos and prices on cards come from the checked asset plan.
- Motion, colours and fonts come from mg-kit. Face placement comes from take-geometry.
- These measurements are a starting point written by us, not copied from a reference. Run learn-style on a reel the creator likes to replace them with measured numbers.
