# whiteout-edit (edit format)

**In plain words:** the screen goes plain white and only big words, numbers or simple drawings appear, like a whiteboard.

**Use when:** the idea matters more than the face: definitions, numbers, before/after.

## Layout
- Pure background from the design system's lightest token, dark text, one accent colour.
- One element appears per spoken phrase (pop-in), building up to a full picture.
- Face returns full-frame between whiteout sections, hard cut.
- Optional small round face bubble bottom-left at 22% width.

## Rules
- Never more than 12 words on the canvas at once.
- If a bubble is used, the face inside is not zoomed past the chin and hairline.
- Only the original's name is public; this layout is ours.
- Motion, colours and fonts come from mg-kit. Face placement comes from take-geometry.
- These measurements are a starting point written by us, not copied from a reference. Run learn-style on a reel the creator likes to replace them with measured numbers.
